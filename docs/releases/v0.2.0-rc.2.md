# GachLagan 0.2.0-rc.2 — Android public preview

[**Download the Android app**](https://github.com/muin99/GachLagan/releases/download/v0.2.0-rc.2/GachLagan-v0.2.0-rc.2-android.apk)

Works on Android 8.0 and newer. No computer, developer account, registration, or encryption server is required. This is a signed release build with debugging disabled.

## Install

1. Open the APK link on your Android phone, then open the downloaded file.
2. Allow your browser to install it if Android prompts, then tap Install. That browser permission can be turned off afterward.
3. Open Gachlagan Keyboard, tap **1. Enable keyboard** and enable it. Return and tap **2. Select keyboard** to select it.
4. Open a messaging app. In keyboard settings, generate a shared key or enter one exchanged with your friend in person. Tap Use these settings.

If you installed an earlier developer/debug APK, preserve your shared keys before uninstalling it. Android requires a matching signing identity for updates; this public release establishes the identity for subsequent official releases.

## Included

- Visible private draft; one-tap Encrypt & insert sends ciphertext to the host app.
- Automatic reading of recognized copied messages while the keyboard is visible, with a manual clipboard fallback.
- Offline AES-256-GCM messaging using a shared random key or passphrase; optional protected device key storage.
- Bangla Avro Phonetic, one-shot Shift/Caps Lock, emoji, compact controls, and an in-keyboard mode picker.
- Public binary, octal, hexadecimal and other encoding modes, labeled separately from private encryption.
- Framed messages so multiple encrypted inserts can be copied and opened together.

## Release status

This is a public **release candidate**, not an independently audited security release. Physical-device and messaging-app coverage remain limited. Shared-key encryption does not provide forward secrecy or protect a compromised phone. [Security details](https://github.com/muin99/GachLagan/blob/v0.2.0-rc.2/docs/SECURITY.md).

iPhone/iPad: source and simulator CI build available; TestFlight/App Store distribution is pending an Apple Developer account. There is no iPhone download in this release.

## Files
