# GachLagan 2.0.1 — Android release

[**Download the Android app**](https://github.com/muin99/GachLagan/releases/download/v2.0.1/GachLagan-v2.0.1-android.apk)

Works on Android 8.0 and newer. No computer, account, registration, or encryption server is required. This is a signed release build with debugging disabled.

## Install or update

1. Open the APK link on your Android phone and open the downloaded file.
2. Allow your browser to install it if Android asks, then tap **Install** or **Update**.
3. Open GachLagan Keyboard, enable it, and select it as your keyboard.
4. Open a messaging app. Generate or enter the shared key exchanged with your friend, then tap **Use these settings**.

## Fixed in 2.0.1

- Settings and message-mode × buttons now return to the correct screen.
- Closing settings cancels unsaved mode, key, visibility, and auto-read changes instead of leaving stale UI state.
- Selected text is removed with one Backspace tap in both the private draft and host app.
- Holding Backspace repeats deletion in the private draft and host app.
- Android emulator coverage now installs the freshly built debug APK explicitly and exercises close/cancel, key settings, selection deletion, held deletion, encryption/decryption, protected key storage, and lifecycle locking.

## Security status

Private messages use offline authenticated AES-256-GCM. The project has not received an independent security audit or broad physical-device review. Shared-key encryption does not provide forward secrecy and cannot protect a compromised phone. See the [security documentation](https://github.com/muin99/GachLagan/blob/v2.0.1/docs/SECURITY.md).

iPhone/iPad source and simulator validation are included, but public iOS distribution still requires an Apple Developer account.
